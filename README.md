# Final_year_project

## Overview
This repository contains a Jupyter notebook for translating text from Odia (OR) to Hindi. The notebook includes dependency installation, imports, data preparation, model training/evaluation logic, and utilities for experimentation.

## Project Structure
- `translation-or-to-hi.ipynb` — Main notebook containing the translation workflow.
- `README.md` — Project documentation.

## Requirements
The notebook installs the following Python packages when executed:
- `sentencepiece`
- `morfessor`
- `sacrebleu`
- `sacremoses`
- `tqdm`
- `seaborn`
- `matplotlib`
- `scikit-learn`

Additional libraries used in the notebook include `torch`, `numpy`, `pandas`, and `sklearn`.

## How to Use
1. Open `translation-or-to-hi.ipynb` in Jupyter Notebook or JupyterLab.
2. Run the cells in order.
3. Review the output and generated artifacts in the notebook environment.

## Notes
- The notebook is intended for experimentation and prototype development.
- You may need to adjust paths, dataset sources, or training parameters depending on your environment.
